# Apex Run

A small offline Android arcade racer. Everything is drawn on a custom Android `View`; it uses no network permissions, external assets, or runtime dependencies.

## Build

Open this project in Android Studio and sync Gradle. Install the app on an Android device running Android 6.0 (API 23) or newer. The first Gradle sync needs internet access to download the Android Gradle Plugin and Android SDK components; gameplay itself works fully offline.

## Play

Tap to start. Tap the left or right side of the road, use the on-screen arrows, or swipe to change lanes. Avoid traffic, tap the pause control to take a break, and beat your locally saved best distance.
